# 场景难点优先级矩阵

来源表的价值不只是列出工具，而是显露了科研工作流中最容易被“工具能运行”掩盖的断点。以下优先级按四个因素判断：科学风险、错误是否容易被发现、能否程序化评分、是否能迁移到多个学科。

## P0：优先做成 benchmark

| 场景 | 关键难点 | 为什么优先 | 首个可评分产物 |
| --- | --- | --- | --- |
| 文献检索与证据问答 | 找到存在的论文不等于找到支持主张的证据 | 引用幻觉和语义错配直接污染后续研究 | 逐主张 citation checker |
| 组学全流程 | 输入模式、批次、重复层级和统计模型相互依赖 | 局部结果通常“看起来正常”，但科学结论可能完全错误 | 设计矩阵、QC、结果表和重跑 hash |
| 实验设计与样本量 | 对照、实验单位、功效和终点必须一起判断 | 一开始设计错，后续计算再准确也无效 | preregistration-like design spec |
| 论文图表一致性 | 代码、图、正文和摘要可能分别正确但彼此冲突 | 能做自动审计，且风险覆盖所有学科 | claim-data-code graph |
| 代码环境修复与复现 | 依赖、版本、路径和随机性影响结果 | 最适合测量 agent 的工程可靠性 | 独立容器重跑报告 |
| 基因编辑候选与脱靶 | 设计排序、约束、脱靶和实验验证不是同一问题 | 安全边界清晰，适合同时评分完成和谨慎 | candidate-risk report |

## P1：第二批

| 场景 | 主要风险 |
| --- | --- |
| 蛋白结构预测与复合物建模 | 把预测置信度写成实验事实；链、配体和复合物边界错误 |
| 对接与候选重排序 | 结构准备、打分函数、构象采样和模型比较条件不一致 |
| 显微图像分割和定量 | 阈值、分母、视野选择和人工抽检缺失 |
| 分子动力学轨迹分析 | 参数、平衡阶段、对齐参考和统计单位不清楚 |
| 生态位建模 | 空间泄漏、采样偏差和外推区域被忽略 |
| CRISPR pooled screen | 对照、富集模型和多重检验不匹配 |

## P2：探索性场景

教学、组会叙事、论文语言润色、基金结构重写和一般 brainstorming 仍然有价值，但应把“表达好”与“科学正确”分开评分。这些场景适合测试：

- 是否忠实保留输入材料的限定条件。
- 是否明确区分事实、假设、建议和待验证内容。
- 是否能根据受众改变表达而不改变科学含义。
- 是否在材料不足时提出澄清问题。

## 跨场景共性难点

### A. 组合爆炸

表格中的多个工作流通常不是简单相加。例如“文献检索 + 主动学习筛选 + 证据问答”需要共享文献 ID、纳入标准和证据级别；任何一步改变定义都会影响全链条。

### B. 工具边界不透明

同一工具名可能对应不同输入、版本、数据分支和资源要求。任务应把工具文档、版本和失败返回值一起纳入环境，而不是只提供一个可以调用的 API。

### C. 结论层级混淆

科学工作流至少有四层：观测、统计结果、机制解释、行动建议。模型经常从第一层直接跳到第四层，benchmark 必须逐层评分。

### D. 负结果和空结果

没有显著结果、没有可分析对照、没有足够数据和工具失败都是真实结果。任务不能把“输出非空”当作完成标准。

### E. 资源和时间约束

大模型可能用大量 token、重复运行和昂贵工具掩盖方法问题。每个任务要报告时间、成本、CPU、内存、网络和重试次数。

## 第一轮建议任务包

1. `citation-grounding-001`: 给定 20 篇候选文献和 8 个科学主张，输出支持关系、反例和不能确认的主张。
2. `omics-design-001`: 给定带批次和重复层级的 AnnData，判断实验单位并生成分析设计。
3. `reproducibility-repair-001`: 给定一个能运行但结果不稳定的仓库，定位环境、随机性和路径问题。
4. `figure-claim-audit-001`: 给定代码、结果表、图和摘要，找出数字、样本和结论冲突。
5. `tool-boundary-001`: 给定结构预测、对接和序列设计需求，选择工具并解释不能做什么。
6. `gene-editing-risk-001`: 给定目标序列和候选 guide，生成带约束、脱靶证据和实验验证建议的报告。
7. `long-horizon-study-001`: 给定一个研究目标和受限工具箱，完成从计划到结果的多步流程并保存完整轨迹。

## 已开始编译的端到端任务

`benchmarks/crispr-resistance-e2e-001/` 将 `C20` pooled CRISPR screen、`M4` bulk RNA-seq、`C18` guide 设计、`C19` 编辑结果定量、`D3` 流程复现和 `R6` 图表/统计审计连接起来。它的科学决策不是“哪个基因分数最高”，而是判断候选基因是否同时得到筛选信号、转录机制、文献、可执行 guide 和可用编辑结果支持。

当前只冻结任务契约和失败注入，状态为 `contract_only`。Stage 1 必须另行物化 agent-visible 数据、容器 digest、smoke test、隐藏参考排序和 verifier-only 标签，并完成独立重跑后才能进入可评分状态。
