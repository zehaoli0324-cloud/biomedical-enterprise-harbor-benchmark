# 科研工作流中的大模型失败模式

这份分类把场景表中的工作流拆成可观察、可复现、可评分的失败单元。一个任务可以同时命中多个类别。

## F1. 问题定义失败

模型没有澄清研究对象、实验单位、终点、约束或成功标准，就直接开始执行。

典型信号：把“组合是否存在非加和效应”误解成“组合是否比对照差异表达”；把“复现论文结果”误解成“写一段看起来类似的代码”。

可测任务：提供一个有歧义的研究请求，要求模型先输出变量字典、假设、排除条件和需要澄清的问题。

## F2. 证据与引用失败

模型生成不存在的论文、错误 DOI、错配的作者和结论，或把摘要中的相关性改写成因果关系。

可测指标：引用存在率、元数据准确率、主张-证据支持率、引用位置正确率、无法核验时的主动标记率。

## F3. 文献检索与筛选失败

模型能找到关键词相关的论文，却不能按纳入标准、研究设计、物种、数据类型或时间范围稳定筛选。

可测任务：给定检索问题、纳入排除标准和一批有干扰的文献记录，要求输出去重后的证据表和排除理由。

## F4. 数据模式识别失败

模型没有正确读取文件格式、元数据、缺失值、批次、单位、重复层级或标签语义，后续分析因此建立在错误输入上。

重点场景：AnnData、单细胞对象、测序计数矩阵、蛋白结构文件、显微图像和实验记录表。

可测指标：数据字典正确率、单位/标签映射准确率、关键异常发现率、未授权假设数量。

## F5. 实验设计与统计失败

模型选择了错误的对照、伪重复的实验单位、不合适的样本量或检验方法，并在结果中报告过度确定的结论。

高风险模式包括：把细胞当成独立生物重复、忽略批次、在多重检验后仍使用未校正的 p 值、把探索性分析包装成验证性结论。

可测任务：要求模型从实验目标和数据结构出发，输出设计矩阵、重复层级、功效假设、分析模型和失败时的降级方案。

## F6. 工具选择与适配失败

模型知道工具名称，但不能判断工具是否适用于当前输入、阶段、物种、数据规模或硬件环境。

典型信号：用 bulk RNA-seq 工具处理单细胞数据；把结构预测工具用于对接排序；在工具作者标注 Draft、链接失效或版本不明时仍然给出“可直接使用”的建议。

可测指标：工具适配准确率、版本约束完整率、无效调用率、替代方案质量。

## F7. 长程工具编排失败

单个命令可能正确，但多步流程中出现顺序错误、参数漂移、状态丢失、文件覆盖或中间产物未检查。

可测任务：提供需要 5–20 步的流程，随机注入一个工具失败、格式变化或空输出，观察模型能否定位并恢复，而不是继续编造结果。

## F8. 代码与环境失败

模型生成的代码不能运行、依赖无法安装、版本 API 不兼容、资源预算不够，或在失败后只修改表面语法。

可测指标：首次运行成功率、修复轮数、环境锁定完整率、CPU/内存/时间预算遵守率、结果重跑一致性。

## F9. 结果解释失败

模型把统计显著误写成生物学重要，把模型分数误写成机制证据，把预测结构误写成实验确认。

可测任务：给出同一数据的多个合理解释，要求模型区分观察、推断、假设和需要验证的主张。

## F10. 可复现性失败

模型给出最终数字，却没有保存输入版本、参数、随机种子、软件环境、过滤规则、中间文件和运行日志。

可测指标：独立环境重跑成功率、输出 hash 一致性、依赖可解析率、关键决策可追溯率。

## F11. 结果到主张的一致性失败

代码、图、表、摘要、正文和补充材料之间存在数字或定义不一致，模型仍将任务标记为完成。

可测任务：给出一套包含轻微矛盾的论文材料，要求模型逐项建立“主张—数据—代码—图表”映射并报告冲突。

## F12. 失败诊断与不确定性失败

模型不能区分数据问题、环境问题、统计问题和科学假设问题；遇到不确定性时继续输出确定答案。

可测指标：根因定位准确率、最小诊断实验选择、合理暂停率、主动请求信息质量、错误自信度。

## F13. 安全与边界失败

模型在湿实验、临床、基因编辑、病原体或隐私数据场景中给出缺少风险控制的可执行建议。

此类任务应评估是否识别风险、是否保留必要的人类审批、是否避免把未经验证的建议写成操作规程。

## F14. 协作与交付失败

模型产出对单个对话有意义，但不符合团队接口：命名不一致、文件层级不对、缺少 README、没有变更记录或无法被下游工具读取。

科研 benchmark 应把交付格式视为任务的一部分，而不是只评分自然语言答案。
