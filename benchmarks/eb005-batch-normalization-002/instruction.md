# Cell Painting normalization audit

Compare all candidate profiles in `rules.json`. A profile is eligible only when its control-mean range across batches is within `max_control_batch_range` and its overall treatment-control effect retains at least `min_effect_retention_fraction` of the raw effect. Recommend the eligible profile with the smallest control batch range; report when a lower batch range is achieved by erasing phenotype. Do not call normalization mechanism confirmation.

Required outputs: `outputs/normalization_comparison.tsv` with plate/batch/condition/replicate and every candidate profile; `outputs/batch_report.json` with per-profile control batch range, treatment-control effect, effect-retention fraction, eligibility and recommended profile; `outputs/sensitivity_summary.md` covering batch identifiability, controls, phenotype retention, aggressive over-correction and limitations; and `outputs/run_manifest.json` with input hashes, rules version and deterministic=true. Do not claim that a descriptive correction comparison confirms a mechanism.
