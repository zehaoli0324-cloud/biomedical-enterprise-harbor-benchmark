# Cell Painting normalization audit

Join `plates.csv` to `plate_metadata.csv` by plate. Only rows in `analysis_scope` with `qc_pass=true` contribute to the decision; pilot and archived plates must remain visible as excluded distractors. First apply the evidence blocker: every batch-condition cell needs at least `min_replicates_per_batch_condition` distinct replicates, otherwise hold without recommending a profile. Compare every candidate profile in `rules.json`. A profile is eligible only when control-mean range, overall effect retention and within-batch direction all satisfy the declared thresholds. Recommend the eligible profile with the smallest control batch range, then the highest effect retention, then lexical profile name. A lower batch range can still be invalid when phenotype is erased or reverses in one batch.

Required outputs: `outputs/normalization_comparison.tsv` with joined scope/QC fields and every candidate profile; `outputs/batch_report.json` with evidence completeness plus per-profile control range, batch effects, effect retention, direction, blocker reasons, eligibility and recommendation or hold; `outputs/sensitivity_summary.md` covering scope exclusions, identifiability, controls, phenotype retention, direction reversal, over-correction and limitations; and `outputs/run_manifest.json` with all input hashes, rules version and deterministic=true. This descriptive comparison does not confirm a mechanism.
