## Added Scientific Decision

All preparations for a contingent policy must be committed before observation.
Setup is charged once per family in the policy-wide union; execution is charged
only for the observed branch. This couples otherwise mutually exclusive branches.
The fixture contains 108 legal complete mappings, competing feasible policies,
correlated-evidence decoys, unavailable sources and an unsatisfied dependency.

The winning policy is P01 with high=M01, low=M05 and mid=M08. It commits F1 and F3
for setup cost 4.0, has worst total cost 6.8, and worst critical residual 0.23.
The cheapest feasible policy loses on residual, and branchwise greedy overspends.
Budget contraction, reduced specialized setup prices and action retraction each
change the optimum. A no-feasible-policy variant correctly requires a hold.

## What the Trial Shows

The model enumerated policies, computed the upfront family union, compared the
minimax objective before cost, and submitted consistent per-state calculations.
All declared inputs were hashed; no contract normalization or semantic repair was
needed. Explicit schemas did not remove the optimization problem, but the small
fully observable search space remained tractable for this model using code.

Seventeen pre-trial controls passed. A separate Fraction-based, setup-first oracle
agreed with the Decimal, action-first verifier on the base and five variants.
Post-trial regression tests additionally reject observed-branch-only setup charges
and repeated charges for the same shared family; they do not alter the frozen
verifier or retroactively redefine this trial. Automated mathematical crosschecks
are not independent human scientific review.

## Transfer and Limits

The reusable mechanism is ex-ante resource commitment across contingent actions:
it could apply to assay preparation, reserved inventory or capacity planning.
These cross-domain transfers remain unvalidated. The SOP and module registry
record the computation, observable outputs, decision flips and negative controls.

A next escalation should add genuine information constraints, such as aliased
observations requiring non-anticipative actions, rather than merely expand the
enumeration or introduce format traps. It should retain the current version as a
calibration anchor and run frozen held-out variants with separate failure labels.

This is synthetic planning, not experimental evidence. Execution used local
process working-directory isolation and a requested network prohibition, not an
enforced container boundary. Container replay, practitioner review and held-out
target trials remain release blockers.
