# Computational biology failure recovery

Preserve the failed branch, compare every successful fallback against the pinned scientific question and allowed parameter changes, select only the claim-preserving fallback, and explicitly reject successful branches that drift the reference or version. Operational success alone does not preserve scientific meaning.

Required outputs: `outputs/execution_log.jsonl` (event/branch/status, using selected/rejected status for fallback disposition), `outputs/failure_recovery.md` (failed branch, partial output, safe fallback, drifted fallback and review boundary), `outputs/claim_ledger.tsv` (claim/status/evidence/review boundary), and `outputs/run_manifest.json` (input hashes, rules version, deterministic=true). Preserve the non-causal boundary semantically; do not claim a biological or causal result.
