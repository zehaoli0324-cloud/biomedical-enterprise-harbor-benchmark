# Synthetic ADTTE fixture

This fixture is a small, frozen calibration input for an ADTTE-like event and
censoring derivation. It is inspired by the public pharmaverse admiral workflow,
but it is synthetic and does not represent sponsor patient data or a clinical
result.

The records expose four endpoint-rule boundaries: competing progression/death
events, an event after the analysis cutoff, missing follow-up, and a month-only
partial date.
